# Project Context Probe

- 测试标记：`PB-CONTEXT-PROBE-V1`
- 生命周期：仅当本文件位于被测项目根目录时视为存在；删除本文件后视为已移除。
- 类型：临时的项目组件说明，不是已经实现或可运行的代码。

## 作用

本组件用于验证新会话能否发现项目结构变化，并准确区分“已经实现的模块”和“只有说明文件的规划组件”。

它规划一个只读的上下文快照导出器：读取项目已有的名称、主要目录和入口信息，生成一份内存中的简短结构摘要，供开发者检查项目导航是否清晰。

## 构成

1. **Metadata Reader**：读取项目名称、主要目录和入口信息。
2. **Structure Summarizer**：把读取结果整理为简短的模块结构摘要。
3. **Read-only Exporter**：将摘要返回给调用方，不写入业务数据。

## 入口与链路

当前只有本说明文件，没有源码入口、命令行入口或接口端点。

规划链路为：`Metadata Reader -> Structure Summarizer -> Read-only Exporter`。

## 边界

- 不修改业务代码或业务数据。
- 不访问外部网络。
- 不应被描述成已经完成、已经接入或可以运行的功能。
- 测试结束后可以直接删除本文件。
